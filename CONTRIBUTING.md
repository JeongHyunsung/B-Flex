# Contributing

## Commit Message Convention

Use this format:

```text
<type>: <short summary>
```

Rules:

- Write the summary in imperative mood (e.g. `add`, `fix`, `update`)
- Keep it short and specific
- Lowercase type

Allowed types:

- `feat`: new feature
- `fix`: bug fix
- `docs`: documentation change
- `build`: build / packaging / CI change
- `test`: tests added or updated
- `refactor`: code cleanup without behavior change
- `perf`: performance improvement
- `chore`: maintenance work

Examples:

```text
fix: add missing BFlexConfig.cmake.in for CMake package config
docs: add pip installation instructions
build: align example option definitions across cpp and python
test: add resume behavior regression coverage
```
